# Gabriele's Master thesis project

Hey, this is my Master's thesis project!

---

My project develops aroung using the **imaging** output of sequencing-based spatial-omics like **Spatial Transcriptomics** and **Spatial ATAC** to connect and integrate different modalities of analysis. Being this a one-in-a-kind approach, I'm mainly focusing on the final comparison between clusters created in this way (images) and clusters derived in the usual way (biological data: RNA and Chromatin Accessibility).<br>



I put a lot of effort in it, so I hope you'll find it interesting and fashinating as much as I did.<br>

Some modifications are still in progress, however, feel free to contact me at: gabriele.gambero1@gmail.com
